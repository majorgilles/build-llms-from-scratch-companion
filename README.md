# Build a Large Language Model (From Scratch) — Companion

A private follow-along workspace for **_Build a Large Language Model (From Scratch)_** by Sebastian Raschka.

## Purpose

Read each chapter from your local copy, then implement the material in its matching notebook. Each notebook intentionally starts with only a title and short introduction.

The source PDF is **not included** in this repository.

## Setup

```bash
uv sync
uv run jupyter lab
```

## Reusing notebook-defined code

This repository uses [nbdev](https://nbdev.fast.ai/) to keep notebooks as the source of truth while exporting selected cells as importable Python modules.

`MultiHeadAttention` is defined in `notebooks/03-coding-attention-mechanisms.ipynb`. After changing an exported cell, regenerate the package:

```bash
uv run nbdev-export --path notebooks/03-coding-attention-mechanisms.ipynb
```

Other notebooks can then import the class without executing Chapter 3:

```python
from build_llms_from_scratch_companion.attention import MultiHeadAttention
```

Files under `build_llms_from_scratch_companion/` are generated by nbdev and should not be edited manually.
